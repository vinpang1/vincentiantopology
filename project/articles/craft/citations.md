# 引述主軸

> 預設規則；擁有者特別要求優先。見 [`README.md`](./README.md) §預設守則。

## 原則

- **中文系列**：引述與例子以中國文化、哲學、經典著作為**主軸**；可按題材引用西方資料，**不寫死、不湊比例**。
- **英文系列**：以西方文化、哲學、經典著作為**主軸**；可按題材引用中方資料，**不寫死、不湊比例**。
- 主軸服務觀測點與觀點；B 閘門與署名標準不變。

## 三層分工

| 層 | 規則 |
|----|------|
| **主軸（預設）** | 策劃／寫前入口先搵主軸傳統嘅材料 |
| **按需補充** | 題材跨文明、對讀、現代議題等 → 另一傳統 0–2 條 |
| **閘門（不變）** | 出街仍須可追溯引證；觀點標準唔因主軸而降低 |

## 中文系列

**主軸例子（非清單上限）：** 經史子集、通識锚（三國、紅樓、詩詞等）、近現代中方思想論述。

**西方何時入：** 題材本身係西方、跨文明對讀、教育／讀寫方法 B、主軸材料不足支撐觀點時。

**格式：** `作者｜書名｜段落`（繁中表頭）

### 書名鎖定（寫死）

- 每篇 `sources.md` **書名鎖定表**：`uuid`／`book_id` → **`canonical_title`**（Spin Map primary shadow 全書名，或 `fetch_download/books.csv` `title`）
- 正文 EFN、《引證索引》書名 **只准抄鎖定表**；禁止用「作者最有名的那本」填表
- 起稿後對照：`引證索引` 每一行 = 鎖定表；正文《書名》= 鎖定表；`入引證索引=Y` 者正文必有錨

## 英文系列

**主軸例子（非清單上限）：** canon essays、Western philosophy、Shakespeare、Plato、主流人文社會科學經典等。

**中方何時入：** 題材明確跨文化、所解讀經典為中方、單一锚點豐富論證且非 tokenism。

**格式：** `Author | Work | Passage`（全文英文）

## 決策流程（寫前）

1. 本篇 `lang` = zh 定 en？
2. 主軸傳統 = 中 定 西（預設）
3. 題材是否強制跨傳統？
4. 引證鏈能否支撐觀點？（唔夠才加另一傳統）
5. 引證表整體是否同主軸一致？（一致即可，唔計百分比）

## 豁免（兩軌共通）

- 入門閱讀手冊（教育／讀寫方法）
- 專題題材決定傳統（跨文明、科技、宗教等）
- **經典解讀**：跟**該書**所屬傳統（解讀《論語》跟中方，解讀 Melville 跟西方）

## 被引作者首次出場（EFN）

> 溯源：Spin Map `11` v1.17 · 本站工序 `w3Pt1xK7` §4.2（引述錨）  
> **適用**：正文第一次提到**引證索引將列入**的 B 層歷史／學術作者。

### 寫死句式（繁中正文）

織入一句，唔另起傳記段、唔用括號貼「作者介紹」標籤：

```text
{英文全名}（{身份}，{生卒年}）在《{書名}》裡{與該段相關的主張}——{極短接到本文}。
```

句內須含三層意思：

1. **誰** — 英文全名、身份、生卒（或約略年代）
2. **主張** — 與該段相關、可核對的一句
3. **接到本文** — 破折號後極短接到當下論點

### 與引述節分工（`w3Pt1xK7`）

有 B 論證小節用 **判準句 → 引述錨 → 落地**（約 1/5 + 1/5 + 3/5）：

- **EFN 放在引述錨**（約 1/5），唔係段落主體
- **一節一個 B 作者**
- 刪走書名後，**落地仍講得通**

### 篇內重複（寫死）

- **同一篇文章**內：引證表每位 B 作者 **第一次**出現 → EFN
- **同篇第二次起**：只用姓／通行稱呼，**唔重複** EFN
- **系列多期**：每期獨立計；**唔**借用他期「已介紹過」
- **一目了然／引言**：避免在正式 EFN 之前先點具名作者；可改寫為「下節引證」「考古主流」等
- **引證索引表**：格式不變（`作者｜書名｜段落`）；EFN 唔改表頭

通順編排（判準四型、禁內部語、S3 演練三拍、起稿自檢）→ [`notes/reader-delivery-zh-TW.md`](./notes/reader-delivery-zh-TW.md) §4

### 例外

| 情況 | 處理 |
|------|------|
| 生卒不詳 | `約前 484–前 425` 等 |
| 全名暫未核對 | 可先用通行姓 + 身份；入庫前補全名 |
| 同作者同篇第二次出現 | **唔**重複 EFN |
| 時事新聞 | 一句標來源＋日期，唔用 EFN |
| 聖經／正典、讀者默識人物 | 唔強制 EFN |

### 唔做

- 長傳記、與本文無關的成就列表
- P 層概念冒充 B 作者口吻（「某書說…」假引述）

### 示例

> **Flinders Petrie**（英國埃及學家、實測考古先驅，1853–1942）在《Ten years' digging in Egypt, 1881–1891》吉薩一章裡記述發掘方法與遺址分層——說明吉薩金字塔不是憑空想像，而是可回到地層與測量的對象。（書名須與該篇 `sources.md` 鎖定表一致。）

**英文系列**：正文以英文撰寫時，姓名用英文、身份與年代同上邏輯；書名用專案慣例（*Title* 或原文書名）。

## 明確唔做

- 為「純中」或「純西」而剔除必要材料
- 大眾文堆三四冷僻人名
- 例子代替觀點；假引述
