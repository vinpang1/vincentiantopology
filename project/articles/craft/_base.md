# 不變層（中／英共用）

> **預設**：無特別要求時跟本檔及 `craft/` 指引；擁有者當次明確要求可覆蓋任何條款。見 [`README.md`](./README.md) §預設守則。

## 觀測點

在具體處境中，追至**第一性原理**後，何種不可替代的**張力／裂縫**被碰到。

- **主體不限於人**：可為人、物件、制度、技術、文本、概念。
- **寫前必答**；禁止用格位、人設、題材標籤代替。
- **檢驗**：換格位、換人設，觀測點句仍應成立。

### 向下四層（寫前工作紙）

1. **處境** — 場景、何者在場？
2. **裂縫** — 邊種張力／限制被碰到？
3. **第一性原理** — 再剝一層，何者不可外包、不可假裝？
4. **觀測點句** — 一句寫死（例：「當 X 被當成 Y，Z 就靜默消失」）

### 通用問句

> 在這個處境裡，**什麼**的**哪一層不可化約的張力**被碰到了？

## 引證 → 消化 → 觀點

| 步 | 內容 |
|----|------|
| **引證** | 事實根據站得住（B 閘門） |
| **消化** | 材料接到觀測點：留／捨／對照 |
| **觀點** | 消化後敢署名的判斷 |

**一篇一命題。** 觀點在引證、消化之後；觀測點在一切手法與語言之前。

---

## 作／寫

- **作**（引證、消化、觀點）— 留人
- **寫**（整理、修飾）— 可交 AI
- **標準**：matter 唔 form — 深淺變打法，唔降引證與署名標準

---

## 工序

```
觀測點 → 引證 → 消化 → 觀點
  → 揀欄目與手法（快／深／厚）
  → 揀語言軌（中／英）
  → [專題] 對位 S1–S4
  → 出稿
```

## 寫前五問

1. 主體：人、物，還是概念／系統？
2. 處境：具體場景一句？
3. 裂縫：哪層張力？（X 與 Y 不能兩全）
4. 第一性原理：再落一層？
5. 觀測點句：一句寫死，且唔依賴格位／人設？
