觀測點、引證、觀點標準不變；本檔只規 **用字深淺與讀者市場**。

## 中文（全站偏大眾）

**目標讀者：大眾市場。**

| 原則 | 說明 |
|------|------|
| **語系** | `lang: zh-Hant` 預設 **台灣書面語**；避免粵語口語殘留（唔、係、邊、定係等），除非擁有者指定其他華語變體 |
| **簡易** | 用字淺白、句子短；少術語、少文言堆砌 |
| **明白** | 讀者唔使查字典先跟到論證 |
| **人話** | 小標像口語；抽象詞要配場景或一句解釋 |

| 欄目 | 詞彙 |
|------|------|
| view / 快打 | 全篇簡易 |
| topics / 深打 | 全篇簡易（可稍密） |
| **classics / 厚打** | **引述可稍深；解讀淺白**（見下） |

**避免：** 為顯深度而堆冷僻字、未解釋的專名、庫內術語。  
**② topics 正文禁內部語**（B 層、庫內、B 錨等）→ 對照表見 [`notes/reader-delivery-zh-TW.md`](./notes/reader-delivery-zh-TW.md) §2。

### 中文 · 經典解讀（classics）

| 層 | 詞彙 |
|----|------|
| **引述**（原文、經文、典籍摘錄） | **可稍深** — 保留經典本身用字；必要時附極短白話釋義 |
| **解讀**（正文：分析、對照、觀點、bridge） | **必須淺白** — 同大眾市場一致 |

**檢驗：** 遮住所有引述，只剩解讀正文 — 仍應係大眾能順讀。

## 英文（按欄目分層）

| 欄目 | 詞彙深度 | 風格參照 |
|------|----------|----------|
| **Vincent View**（`view`） | **簡單** | 短句、日常詞、低門檻 |
| **Special Topics**（`topics`） | **簡單～適中** | **商業文章**：主流大型刊物評論／觀點欄 — 清晰、有力、少學術腔 |
| **Classic Commentary**（`classics`） | **可較深** | 可承載較長句、專名與文學用語；仍須一句一義 |

### Vincent View

- 假設讀者掃一眼；一句一個意思
- 避免 journal jargon

### Topics（商業文章取向）

- 像主流大型刊物觀點欄：論點清楚、有節奏、可引用
- 專名首次出現可極短界定
- 唔寫成 peer-reviewed abstract

### Classics

- 可保留文學與思想史用語
- 段落仍須可掃讀；觀測點與觀點唔埋沒於辭藻

## 與手法對照

| | 中文詞彙 | 英文詞彙 |
|---|----------|----------|
| 快打 · view | 大眾簡易 | Vincent View · 簡單 |
| 深打 · topics + S1–S4 | 大眾簡易 | 簡單～適中 · 商業文 |
| 厚打 · classics | 引述可稍深；解讀淺白 | 可較深 |

**matter 唔 form：** 淺詞可以講深觀點；深詞唔可以代替觀點。

## 交 AI 整理時

- 註明欄目與語言軌（例：`zh-topics-S2` / `en-view`）
- 附上本檔對應段落；**唔**叫 AI 自行升級詞彙
- 中文經典：引文保持典籍用字；解讀全部淺白句
- 終審：有冇「為顯聰明」而加的詞？
