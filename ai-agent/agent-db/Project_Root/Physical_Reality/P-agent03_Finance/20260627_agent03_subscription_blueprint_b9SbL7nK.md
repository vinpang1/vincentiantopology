## 1. 品牌定位

| 項目 | 定案 |
|------|------|
| **對外類型** | 思想雜誌（可不同主題／系列） |
| **一句話** | 給願意慢讀的人一本線上雜誌：專題研究、時事與科技、經典與人物；同一套讀法，不同題材 |
| **方法（固定）** | 思想對碰 · 引證→消化→觀點 · 寫作金字塔（讀→作→寫）· 0 閱讀手冊憲章 |
| **題材（可變）** | 科技、管理、經典、都市傳說／靈性敘事等 |
| **舊母檔** | Spin Map `DUjEgIF1`（9.9 分層牆）→ **本檔優先**；P 層策略語、價格 **唔** 直接出街 |

### 目標客戶

1. **內容創作者** — 敘事結構、讀法方法  
2. **專業管理人** — 判斷力、資訊與謠言紀律  
3. **都市傳說／靈性興趣讀者** — 深度讀敘事，**唔**賣神秘學結論  

收斂句：**需要一套穩定讀法，去處理不同類型敘事的人。**

## 2. 產品 · 單一訂閱 · 三欄

**一個訂閱，全包；唔再拆分 SKU。**

| 欄目（對讀者） | 對應產品線 | 本站欄目 | 節奏（承接舊產能） | 角色 |
|----------------|------------|----------|-------------------|------|
| **專題研究** | ② 專題 | `/topics` | 週 1 · ~1500 字 | 封面故事／連載 |
| **時事評論／最新科技** | ① 時事 | `/view` | 週 1–2 · 300–500 字 | 快訊欄 |
| **經典著作・人物分析** | ③ 經典 | `/classics` | 月 1 · 長文（彈性） | 長文欄 |

| 固定免費 | 路徑 | 備註 |
|----------|------|------|
| **入門閱讀／閱讀手冊** | `/intro` 0-1～0-4 | 憲章級；思想對碰、訂閱讀法、AI 分工 |
| **社交漏斗** | ④ Threads · IG · X · FB | 第一漏斗；正文 **唔提訂閱**（`t4CrTn7K`） |

### 漏斗

```
④ 社交
   ↓
① 時事（公開站可 teaser）
   ↓
0 閱讀手冊（憲章）
   ↓
訂閱平台（三欄全文 · Phase 1 免費）
```
