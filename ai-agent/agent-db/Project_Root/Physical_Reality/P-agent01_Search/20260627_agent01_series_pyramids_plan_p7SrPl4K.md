## 3. 各期作層工作紙（v2）

### Ep1 · S1 · construction-archaeology

**作者閱讀契約（引言寫死 · 用戶定案）**

> 金字塔是不是外星人建的？**我不知道。**  
> 我不是回避——我們回不去施工現場，手邊只有文獻、遺址與後人的測量。我也有直覺和猜想；但這系列的規矩很簡單：**猜想可以，但要拿證據來對線。**  
> 第一期不裁判「誰建的」；只畫一張圖：哪些話算可核對、哪些只是合理推斷、哪些還在爭論、哪些該誠實留白。

**證據四格（本篇核心工具 · 一目了然必寫）**

| 格 | 讀者問句 | 金字塔示範 |
|----|----------|------------|
| **① 可核對** | 遺址／測量／可對照文本？ | Petrie 測量、墓室結構 |
| **② 合理推斷** | 文獻＋遺址串得起，但未目擊？ | 斜坡形式、季節性換班 |
| **③ 爭議中** | 學界仍辯？ | 希羅多德數字是否全實 |
| **④ 空白** | 誠實不知？ | 每日工序、部分銘文 |

**實／墟**

| | |
|--|--|
| **實** | 吉薩三座塔、遺址痕跡、近代測量與文獻場 |
| **墟** | 讀者猜想（含外星）、驚嘆、完整故事感 |

**四層**

| 層 | 內容 |
|----|------|
| 處境 | 人人講同一座塔，故事卻分裂；無法在場 |
| 裂縫 | **可核對** 與 **好聽完整故事** 之間的距離 |
| 第一性原理 | 猜想要對證據負責；推斷必須標明邊界 |
| **觀測點句** | 當「誰建的」被講到太順，**證據格子的分界**反而消失 |

**署名觀點（篇級）** | 我不知道誰建的，但我知道什麼不能當證據——先把四格畫清，後面所有爭論才有地圖。

**內容節（2–3 節 · 示範入格 · 非百科）**

1. **陵墓最低共識** — Rawlinson 一錨；示範 ①②  
2. **材料與人力** — Burr／希羅多德；示範 ②③（數量級敘事）  
3. **精度** — Petrie 一節；示範「驚嘆誤入 ①」  

**交付備註** | 不駁外星（留 Ep3）· 每期工具：讀任何段落前先問**屬於哪一格** · `description` 副標可寫：外星人？人力？我先不選邊。

**實／墟**

| | |

**四層**

| 層 | 內容 |
|----|------|
| 處境 | Ep1 四格已立；中文讀者常把吉薩與上古中國並讀 |
| 裂縫 | **時間重疊** 被誤讀為 **文明可比** |

| **觀測點句** | 當「同期」被當成「同級」，各自的時間表會被靜默抹平 |

**署名觀點（篇級）** | 並讀兩文明前，先分軸——不是比優劣，是比各自證據語言。

### Ep4 · S4 · reading-method

**實／墟**

| | |
|--|--|
| **實** | 同一批文獻可被編成相反情緒結論 |
| **墟** | 官方太整齊不信、另類太好讀不知怎麼分辨 |

**陰謀三層（精簡演練 · 非事實主張）**

| 層 | 對應 Ep1 格子族 | 線索 |
|----|-----------------|------|
| **事實層** | ① | 空墓、遺址缺口 |
| **推斷層** | ②③ | 整齊數字、工程可行性 |
| **敘事層** | 讀者情緒 | 標籤反噬、「被隱瞞」感 |

**S4 方法總裝（7 項 · 已鎖）**

```text
讀史前／上古史總裝：
1. 我讀的是文獻層還是考古層？
2. 「同期」是時間重疊，還是能力可比？
3. 哪一段年表在 retrojection（後代回填上古）？
4. 這句話在四格的哪一格？
5. 逃逸敘事過不過三關？
6. 我滿足的是事實、推斷，還是敘事層？
7. 換一把「文明卡尺」，排名會怎麼變？
```
