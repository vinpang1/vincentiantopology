## 2. 第一部 · 觀測（一切之前）

### 2.1 定義

在具體處境追到第一性原理，問：**哪一層不可化約的張力被碰到？**（`craft/_base.md`）

### 2.2 四層工作紙

| # | 層 | 問 |
|---|-----|-----|
| 1 | **處境** | 場景、何者在場？ |
| 2 | **裂縫** | 邊種張力／限制被碰到？ |
| 3 | **第一性原理** | 再剝一層，何者不可外包、不可假裝？ |
| 4 | **觀測點句** | 一句寫死（例：「當 X 被當成 Y，Z 就靜默消失」） |

**通用問句**：在這個處境裡，**什麼**的**哪一層不可化約的張力**被碰到了？

### 2.3 實墟透鏡（`yeqyXays`）

| 問 | 意思 |
|----|------|
| **什麼是實？** | 本篇 hub：場景／時點／文本場面／當週事件錨 |
| **什麼是墟？** | 掛在實上：人、制度、概念、關係、器物、讀者位置 |

**入口只揀一個**：場景軸 · 人物軸 · 關係軸 · 地點／器物軸。

**鐵律**：實墟定錨之後，先准開第二部。  
**禁止**：八格、亞哈線、熱詞、SWOT 標籤代替觀測點。

### 2.4 可選 · 四透鏡（`wOZGBy1F`）

各問一輪 → 只列 **裂縫句**，唔寫立場：需求 · 第一性原理 · 哲學柱 · 心理動力。

### 2.5 觀測完成檢驗

- [ ] 換格位、換人設，觀測點句仍成立？
- [ ] 唔依賴題材標籤、人設、敘事線？
- [ ] 若把「實」換成另一層，觀測點句會唔會變味？（會 → 未寫死）
- [ ] **一篇一命題**

## 3. 第二部 · 消化（工具 + 引證）

### 3.1 定義

材料接到觀測點：**留／捨／對照** → **敢署名嘅判斷**。觀點在引證、消化之後。

### 3.2 引證閘門

| 層 | 角色 |
|----|------|
| **B** | 事實根據、可核對引述（出街引證表） |
| **A** | 時事材料；正文可標來源，**唔入 B 引證表** |
| **P**（Spin Map / 庫內修練） | 方法、心得 — **禁 copy 出街** |

**操作句**：**P 負責跳；B／A 負責證。** 編目只產待證假設；出街論斷須返 B 正本。

### 3.3 工具箱（按需 · 唔必全套）

| 工具 | 用途 | 唔做乜 |
|------|------|--------|
| **2³**（`wOZGBy1F`） | 三軸交叉，檢驗漏睇、硬湊 | 文章分節；觀測點本體 |
| **思想對碰**（`Xm95Uvzb`） | 問題 × 材料 → 觀點 | 跳過 → 噪音 |
| **八格**（`K4LEU0SI`） | 受眾／漏睇檢驗 | 觀測點；八段結構 |
| **SWOT／XX 分析法** | 制度、商業、政策題 | 每篇硬套 |
| **聯想／引力** | **裂縫句之後** 搵材料 | 聯想順代替裂縫真 |
| **編目跳→正本證**（紅樓式） | 長文本、經典 | CSV 直接寫長文唔返正本 |

**建議次序**：

```
裂縫句 → [可選] 2³ → 思想對碰 → 署名觀點 → 先至揀交付軌
```

### 3.4 消化完成檢驗

- [ ] 每條判斷追得到 B（或標清 A／待核）？
- [ ] 刪走最鍾意嘅敘事線，觀點仍成立？
- [ ] 有冇用觀點倒插觀測點？（有 → 噪音）
- [ ] 署名觀點一句寫得出？（全篇收束用）

### 4.2 引述節紀律 · 1/5 + 1/5 + 3/5（`46vnCD64` v1.3）

**用途（寫死）**：**主要用在有 B 引述嘅論證小節** — 避免引述像背書開場（權威先講、觀點埋後）。

| 部分 | 約比重 | 做乜 |
|------|--------|------|
| **判準句** | 1/5 | 本節暫定判斷；一句為宜；**觀測≠呢句** |
| **引述錨** | 1/5 | **一個 B 作者** + 一句可核對主張（**EFN 式** → `project/articles/craft/citations.md` §被引作者首次出場） |
| **落地** | 3/5 | 當週時事、可查指標、讀者誤區、對照觀測點 |

**小節順序**：

```
判準句（1/5）→ 引述錨（1/5）→ 落地（3/5）
```

**操作句**：

- **一節一個 B 作者**
- **EFN 係錨，唔係段落主體**；刪走書名後，落地仍講得通
- 判準句係可帶走半句判斷，唔係口號；**唔每節同一模具**（四型輪替、全篇否定問句 ≤2 → `craft/notes/reader-delivery-zh-TW.md` §4）
- **「我的看法」「總結」「待續之問」**：跨節收束，**唔再加 B**

**唔適用**（唔硬套比例）：引言、一目了然、無 B 引述段落；`classics` 深引跟 `hzBev1EF` 引述分層。

### 4.3 引述節樣板

```text
【判準】（1/5）我暫時唔把 X 讀成 Y。
【引述】（1/5）Author｜Work｜一句原著核心主張。
【落地】（3/5）對照當下、讀者誤區、可查指標；回扣全篇觀測點。
```

### 4.4 引述節四問（反背書）

- [ ] 刪作者書名，第一句仍係你嘅判斷？
- [ ] 判準有 **輪替**（陳述／短問／肯定暫定／否定問）？全篇否定問句 ≤2？
- [ ] 引述只得 **一句** 核心主張？
- [ ] 落地大部份講當下／誤區，唔係書評摘錄？
- [ ] 全篇觀測點冇被複讀成每節口號？
