# 07 — V-S 矩阵 · vsm（agent-db）

> 跟 Spin Map v1.8.0 · 参考：[`spin-map/docs/ai/02_METADATA_INVARIANTS.md`](../../../_shared/spin-map/docs/ai/02_METADATA_INVARIANTS.md) §vsm

**废止**：旧 `v1～v16` 浮点栏 → 仅用 **`vsm`**（9 位字符串）。

---

## 1. 设计原则

| 坐标 | 基数 | 维 | 用途 |
|------|------|-----|------|
| **qutrit** | 3 | 6 | 物理路径 · `The_Void_729/`（见 **08**） |
| **vsm** | 5 | 9 | 语义搜索 · 与 qutrit **正交** |

`vsm` 回答「这份 shadow **是什么**」；qutrit 回答「放在 **哪里**」。

---

## 2. V 轴 V1–V9

| 位 | 代号 | 名称 | 语义 |
|----|------|------|------|
| 0 | V1 | Data | 硬数据、常数、基础代码 |
| 1 | V2 | Math | 公式、定理、定义（静态） |
| 2 | V3 | Algo | 算法、流程、步骤 |
| 3 | V4 | Sys | 架构、模块、框架 |
| 4 | V5 | Dyn | 演化、迭代、反馈 |
| 5 | V6 | Manifold | 高维、拓扑、对偶 |
| 6 | V7 | Ethic | 社会、人机、伦理影响 |
| 7 | V8 | Synth | 跨域、隐喻（须可反指 V1–V6） |
| 8 | V9 | Singularity | 终极理论、纯理论 |

**V2–V5 防重叠**：静态公式→V2 · 步骤→V3 · 结构→V4 · 时间演化→V5  
多维适用时优先：**V1 > V2 > V3 > V4 > V5 > V6**

---

## 3. S 状态 S0–S4（每位 vsm 数字）

| 数字 | 代号 | 名称 | 语义 |
|------|------|------|------|
| **0** | S0 | N/A | 此 V 轴对本 shadow **完全不适用** |
| **1** | S1 | Static | 静态定义、结构 |
| **2** | S2 | Dynamic | 过程、运算、流程 |
| **3** | S3 | Superposition | 未确定、开放问题 |
| **4** | S4 | Collapse | 已确定（无论正负） |

**没有 S5。** Spin Map 仅 S0–S4。

**S0 vs S1**：S0 = 维度不适用；S1 = 适用且为静态定义。

---

## 4. vsm 格式

```yaml
vsm: "203040320"
#      ^^^^^^^^
#      V1 V2 V3 V4 V5 V6 V7 V8 V9
```

- 9 位纯数字，每位 **0–4**
- 不涉及 → `0`（S0）
- 涉及 → 按内容填 1–4（S1–S4）
- **Bucket 不限制** 可填哪些 V 轴

### 命名防混淆

| 符号 | 含义 |
|------|------|
| `d4` | 时间姿态（D4） |
| `d5` | 认证程度（D5） |
| `vsm[3]` | **V4_Sys** ≠ d4 |
| `vsm[4]` | **V5_Dyn** ≠ d5 |
| `gravity_links` | 跨 uuid · ≠ D1–D6 |

### V8 规范

若 vsm 第 8 位（V8）≠ `0`，正文 V-S 表须说明能反向对应至少一个 **V1–V6** 命题；否则强制 `0` 并标 `[V8_decorative]`。

## 5. 正文必填：### V-S 矩阵

9 行表格（V1–V9），每行含：

| 列 | 内容 |
|----|------|
| 位序 | 0–8 |
| 维度 | V1 Data … V9 |
| vsm 值 | 0–4 |
| S 状态 | S0–S4 |
| 活性 | ● 活性 / ○ 不适用 |
| 选取理由 | 一句 |

末尾附 S 状态图例。

---

## 6. 填写步骤

1. 通读 shadow 视角内容（非仅 bucket 标签）
2. 逐 V1–V9 问：「本 shadow 是否实质涉及？」
3. 否 → `0`；是 → 判 S1/S2/S3/S4
4. 写入 YAML `vsm` 与正文 9 行表
5. 同一 uuid 不同 shadow → **独立** vsm

---

## 7. 示例

Agent 操作规格类 shadow（流程 + 系统规则）可能类似：

```text
vsm: "102140000"
V1=1(S1 结构) V2=0 V3=2(S2 流程) V4=1(S1 框架) V5=4(S4 已定规程) …
```

确切值须按正本内容评估，不可模板硬填。
