## 3. 逐维指南（摘要）

### D1 可信度
偏低：逻辑跳步、已被驳斥 · 中段：仍争议 · 偏高：教科书定论、广泛共识  
**≠ D5**（社会接受 vs 证据强度）

### D2 题材层次
1–3 生存（经济、财务、底层法律）· 4–5 社会 · 6–8 精神（哲学、文学）

### D3 论述形式
1–2 描述（年表、档案）· 3–5 分析 · 6–8 规范（政策、伦理应然）  
**≠ D6**（论述类型 vs 论证深度）

### D4 时间姿态
-1 历史 · 0 现行有效 · +1 前瞻规划

### D5 认证程度
偏低：传闻 · 中段：假说 · 偏高：可复现实验、可核对数据

### D6 推导深度
偏低：摘录综述 · 中段：文内推理链 · 偏高：公理出发
